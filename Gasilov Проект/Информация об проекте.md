## **Слайд 2: Проблематика и решение**

**Давайте посмотрим на текущие проблемы:**

1. **Ручное создание диаграмм** — занимает 40% рабочего времени администраторов. Это часы, которые можно было бы потратить на решение реальных технических задач.

2. **Устаревшие схемы** — становятся причиной 30% ошибок при устранении неисправностей. Когда диаграмма не соответствует реальности, это создает критически опасные ситуации.

3. **Отсутствие стандартизации** — каждый администратор рисует схемы по-своему, что затрудняет передачу знаний и командную работу.

**Мое решение — интеллектуальный генератор сетевых диаграмм:**

1. **Автоматическое создание** — система сама генерирует профессиональные схемы из описания конфигурации.

2. **Визуализация в реальном времени** — любые изменения в сети мгновенно отражаются на диаграмме.

3. **Стандартизированный экспорт** — единый формат для всей документации компании.

def auto_layout(self):
    # Разделяем устройства по типам
    routers = [d for d in self.devices.values() 
               if d.device_type == DeviceType.ROUTER]
    
    # Располагаем маршрутизаторы по кругу
    for i, router in enumerate(routers):
        angle = 2 * math.pi * i / max(len(routers), 1)
        router.x = center_x + radius * math.cos(angle)
        router.y = center_y + radius * math.sin(angle)
```

**Этот алгоритм использует математику для оптимального расположения:** маршрутизаторы в центре, коммутаторы вокруг них, серверы сверху, клиенты снизу. Это делает схемы интуитивно понятными.

def draw_device(self, device: NetworkDevice):
    colors = {
        DeviceType.ROUTER: '#4CAF50',      # Зеленый
        DeviceType.SWITCH: '#2196F3',      # Синий
        DeviceType.SERVER: '#FF9800',      # Оранжевый
        DeviceType.FIREWALL: '#F44336',    # Красный
    }
    
    # Для каждого типа устройства - своя фигура
    if device.device_type == DeviceType.ROUTER:
        patch = patches.Circle((device.x, device.y), 0.8)
    elif device.device_type == DeviceType.SWITCH:
        patch = patches.Rectangle((device.x-0.7, device.y-0.7), 1.4, 1.4)
    elif device.device_type == DeviceType.SERVER:
        # Ромб - квадрат, повернутый на 45 градусов
        diamond = patches.RegularPolygon((device.x, device.y), 4, radius=0.8)
        diamond.set_transform(diamond.get_transform() + 
                             Affine2D().rotate_deg(45))
```

**Генерация полной диаграммы:**

```python
def generate(self):
    # 1. Автоматическое расположение
    self.auto_layout()
    
    # 2. Рисуем все соединения
    for connection in self.connections:
        self.draw_connection(connection)
    
    # 3. Рисуем все устройства (поверх соединений)
    for device in self.devices.values():
        self.draw_device(device)
    
    # 4. Добавляем легенду и заголовок
    self.draw_legend()
    self.ax.set_title(self.title, fontsize=16, fontweight='bold')
```

**Этот метод реализует конвейер обработки:** данные → расположение → отрисовка → финальное оформление.
